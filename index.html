TECHWIZ-2142 abs-widget: click student name to open prefiltered absence administration Absenzen: Direktzugriff auf Absenzhistorie über das Widget „Absenzen meiner Lernenden“ Im Widget „Absenzen meiner Lernenden“ auf der Startseite können Lehrpersonen neu direkt auf den Namen einer Schülerin oder eines Schülers klicken. Sie gelangen dadurch direkt in die Absenzverwaltung, bereits gefiltert auf die betreffende Person und das aktuelle Semester. So lässt sich die gesamte Absenzhistorie einer Person ohne manuelles Suchen einsehen. 1d In Refinement
TECHWIZ-2141 abs-widget: show school absenteeism warning icon for matching students Absenzen: Warnsymbol für Schulabsentismus im Widget „Absenzen meiner Lernenden“ Im Widget „Absenzen meiner Lernenden“ auf der Startseite wird bei Schülerinnen und Schülern, die den definierten Schwellenwert für Schulabsentismus erreichen, neu ein Warnsymbol angezeigt. Beim Bewegen der Maus über das Symbol erscheint der Hinweis "Schulabsentismuswarnung". So erkennen Lehrpersonen auf einen Blick, bei welchen Lernenden ein auffälliges Absenzmuster vorliegt. 1d In Refinement
TECHWIZ-2140 abs-configuration: configure school absenteeism threshold Absenzen: Schwellenwert für Schulabsentismus konfigurieren In der Absenzkonfiguration kann neu ein Schwellenwert für Schulabsentismus definiert werden: Zeitraum in Wochen, Anzahl unabhängiger Absenzen und die dafür relevanten Absenzgründe. Eine unabhängige Absenz ist dabei eine Absenz, die nicht an aufeinanderfolgenden Tagen liegt. Mit dieser Konfiguration lassen sich wiederkehrende Absenzmuster im Widget „Absenzen meiner Lernenden“ einfacher erkennen. 1d In Refinement
